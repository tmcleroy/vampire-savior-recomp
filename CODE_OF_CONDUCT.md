# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, patient and respectful; criticize ideas, not people; no harassment,
insults, or sexual or discriminatory language or imagery; and respect people's privacy. This
applies in issues, pull requests, discussions and anywhere else you represent the project.

If someone's behavior makes you uncomfortable, please report it privately to the maintainer
at tmcleroy@gmail.com. Reports are kept confidential. The maintainer may edit or remove
contributions, and warn, or temporarily or permanently ban, anyone who breaks this code, as the
Contributor Covenant's enforcement guidelines describe.
